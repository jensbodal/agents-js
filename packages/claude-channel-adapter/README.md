# @agents-js/claude-channel-adapter

> Claude Code receiver-side MCP server for the wake-adapter family. Declares the experimental `claude/channel` + `claude/channel/permission` capabilities so Claude Code registers a listener for `notifications/claude/channel` (capability-gated, per Anthropic Channels protocol research-preview ~v2.1.80+); subscribes to gateway wake/inbox events and emits push messages into running Claude Code sessions. Bidirectional: also exposes `agents_js_reply` + `agents_js_send` outbound tools for CC → mesh replies. Per ADR-0007 §Revision-2026-05-28.

## Installation

```sh
bun add @agents-js/claude-channel-adapter
```
