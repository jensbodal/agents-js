# Security Policy

## Supported Versions

`agents-js` is currently in an internal beta phase. Security fixes are only guaranteed for the
latest checked-in beta line documented in [docs/beta-contract.md](docs/beta-contract.md).

## Reporting A Vulnerability

Please do not file a public issue for a suspected vulnerability.

Report security issues privately to:

- `jens@bodal.dev`

Include:

- the affected package or surface
- reproduction steps or proof-of-concept details
- the observed impact
- any suggested mitigation if you already have one

You will receive an acknowledgment and follow-up on severity, fix scope, and disclosure timing.
